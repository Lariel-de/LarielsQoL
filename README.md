# Lariel's Quality of Life (QoL)

**Lariel's Quality of Life** is a feature-packed utility and expansion mod for Pixelmon. Designed to enhance the everyday gameplay experience for both players and server admins, this mod brings advanced trackers, versatile trading systems, breeding improvements, and essential QoL mechanics—most of which can be customized or toggled via config!

---

## 🌟 Key Features

### 📡 Entity & Spawning Trackers

Never miss a rare encounter again! The mod tracks special spawns and sends an interactive chat notification:

* **Trackers Included:** Shiny, Legendary, Palette, Boss, and Ultra Beast Pokémon.
* **Wayfinding System:** Clicking the link in the chat notification renders a direction arrow pointing you directly toward the tracked entity.

### 🍃 Mint Trader NPC

* **Function:** A specialized NPC vendor allowing players to trade in **9 arbitrary Mints** in exchange for the exact Mint of their choice.

### 🐣 Better Breeding NPC

* **Egg Editing:** An interactive NPC interface allowing players to modify eggs currently held in their party (e.g., Palette, Form, and Gender).
* **Undiscovered Egg Groups:** Allows breeding of Pokémon from the *Undiscovered* egg group after unlocking a configurable Achievement.
* **Fully Configurable:** Admins can set individual prices for each modification or disable specific edit options entirely.

### 🏪 Custom Trader System

* **Data Pack Support:** Create new Pixelmon-style Traders using custom Data Packs.
* **Multiple Currencies:** Supports PokéDollars, custom Items, or Scoreboard points as currency.
* **Tier Progression:** Features up to 5 unlockable trading levels per merchant, unlocking new trades as players level them up (rebuilt to mirror Vanilla trading mechanics).
* **Pre-configured:** Comes with an included Example Trader and recreated Vanilla Pixelmon traders out of the box.

### 🛡️ "I Want It!" Protection

* **In-Battle Safeguard:** Click the "I Want It" button in battle to protect a target wild Pokémon.
* **Damage Lock:** Protected Pokémon cannot drop below 1 HP from direct attack damage!
* **⚠️ Warning:** Be careful! Weather conditions, status ailments (Burn, Poison, etc.), and recoil effects can still faint the protected target.

### 🎒 Pokébag Hotkey

* Open your Pokébag instantly at any time using a customizable hotkey (Default: **`P`**).

### 🥚 Hatching Enchantment

* **Chestplate Enchantment:** A dedicated enchantment for body armor that reduces the number of steps required to hatch eggs by **50%**.

### 👨‍🌾 Lariel Villager Spawn Egg

* Spawns a true Vanilla-style Villager NPC that bypasses Pixelmon's entity replacement logic and acts exactly like a vanilla villager.

---

## ⚙️ Configuration & Customization

Nearly every feature in **Lariel's QoL**—from tracker toggles and enchantment strengths to breeding costs and trader currencies—can be fully adjusted or disabled through the main configuration file to fit any server balance.
